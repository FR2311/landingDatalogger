DATALOGGER / MANUAL DE USUARIO

El equipo, en tus manos.

Una guía para consultar datos, configurar el registro y resolver los problemas más habituales del DataLogger.

GUÍA DE CONSULTA

Uso y diagnóstico del equipo.

01 / PRIMER USO

Puesta en marcha

Si es la primera vez que utilizás el equipo, seguí la guía de conexión. Para los siguientes encendidos, prepará la microSD, conectá la alimentación y comprobá que el dispositivo inicie correctamente.

Consultar Quick Start →
02 / CONEXIÓN

Volver a entrar al panel

Conectá tu equipo a la red del ESP32 o a la misma red local configurada en el firmware. Abrí http://IP_DEL_ESP32/ con la dirección actual del dispositivo.

Si la dirección anterior no responde, revisá la IP en el Monitor Serie a 115200 baudios. Puede cambiar al reconectarse a un router o hotspot.

03 / CONSULTAS

Filtrar y exportar registros

Abrí Historial, elegí las fechas, la variable y el intervalo, y aplicá el filtro. Revisá el período seleccionado antes de exportar los registros en CSV.

Ver la pantalla de Historial →
04 / CONFIGURACIÓN

Cambiar el registro y las alertas

En Configuración, seleccioná el intervalo de muestreo y la retención. Ajustá las unidades, definí los límites de alerta y guardá los cambios.

El selector de tema permite elegir el modo oscuro; las preferencias de visualización se conservan para los próximos accesos.

Ver la pantalla de Configuración →
05 / ALMACENAMIENTO

microSD y actualización del frontend

La tarjeta conserva los CSV en /data/ y la interfaz en /www/. Apagá el equipo antes de retirarla.

Si el firmware tiene habilitada la administración, usá http://IP_DEL_ESP32/admin para cargar los archivos del frontend sin extraer la tarjeta.

06 / ESTADO

Comprobar los módulos

Revisá el estado del BME280, RTC, SD y WiFi antes de interpretar una lectura o investigar un problema. Un módulo no disponible requiere revisar sus conexiones y alimentación.

Consultar la referencia de la API →
07 / DIAGNÓSTICO

Comprobar la conexión

Confirmá la red y la dirección actual. Desde una terminal de Windows, podés comprobar la comunicación y el servidor: 

ping IP_DEL_ESP32
Test-NetConnection IP_DEL_ESP32 -Port 80

Luego comprobá la respuesta de la API para distinguir un problema de red de uno del frontend.

08 / SOLUCIONES

Resolver problemas habituales

Sin lecturas: revisá el sensor y sus conexiones. Hora incorrecta: comprobá el RTC. Sin registros: revisá la microSD.

La API responde pero el panel no abre: verificá que /www/index.html y los recursos del frontend estén presentes en la tarjeta.
