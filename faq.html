DATALOGGER / FAQ

Respuestas para seguir.

Conexión, sensores, almacenamiento y uso cotidiano. Abrí una pregunta para consultar su respuesta.

¿Necesito Internet para usar el DataLogger?

No para el uso local. Conectate a la red propia del ESP32 y abrí la dirección del dispositivo. La interfaz publicada y los servicios externos sí requieren acceso a sus respectivas redes.

¿Puedo usar el hotspot de mi celular?

Sí. Activá un hotspot de 2.4 GHz y conectá el ESP32 y la computadora a esa red. El hotspot debe permitir la comunicación entre los dispositivos conectados.

¿Por qué cambia la IP?

El router o el hotspot suele asignar la IP automáticamente mediante DHCP. Al reconectar el ESP32 puede entregarle una dirección diferente.

¿Cómo puedo conocer la IP del ESP32?

Abrí el Monitor Serie a 115200 baudios y buscá la dirección mostrada después de la conexión WiFi. Usá esa IP en el navegador desde un equipo de la misma red.

¿Cómo compruebo si el ESP32 está conectado?

Revisá los mensajes del Monitor Serie y abrí http://IP_DEL_ESP32/api/actual con la IP del equipo. Si recibís las mediciones, la conexión y el servidor HTTP están respondiendo.

¿Qué significa bme280=true?

Indica que el firmware detectó el sensor ambiental BME280 y lo informa como disponible. Si aparece false, revisá el sensor, la alimentación y sus conexiones.

¿Qué significa rtc=true?

Indica que el reloj RTC DS3231 fue inicializado y está disponible. Si la fecha u hora son incorrectas, revisá también la configuración del reloj.

¿Qué significa sd=true?

Indica que la microSD está disponible para el sistema. Si aparece false, comprobá la tarjeta, el módulo lector y sus conexiones.

¿Dónde se guardan las mediciones?

Las mediciones se guardan localmente como archivos CSV en la carpeta /data/ de la microSD. Podés consultarlas desde el historial o descargarlas mediante la exportación.

¿Qué pasa si reinicio el ESP32?

El firmware vuelve a inicializar los módulos y retoma el registro. Los archivos ya guardados en la microSD permanecen; las mediciones se interrumpen mientras el dispositivo está apagado o reiniciándose.

¿La interfaz muestra datos reales?

La interfaz del dispositivo consulta las mediciones del ESP32. La galería de esta web muestra capturas proporcionadas por el equipo: sus valores son los registrados en esas imágenes y no se actualizan en vivo.

¿Por qué /api/actual funciona pero la página principal no?

Si la API responde, revisá los archivos del frontend en la microSD. Debe existir /www/index.html, junto con sus archivos de estilos y JavaScript.

¿Debo subir las credenciales WiFi a GitHub?

No. Configurá las credenciales únicamente en tu entorno local. El repositorio público debe usar marcadores de ejemplo y nunca contraseñas, tokens ni información privada.
